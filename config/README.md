# Config

## Purpose
Application configuration files including environment settings, database configuration, logging setup, and reference data.

## Files
- `settings.py` — Application constants and environment variables
- `database.py` — Database connection configuration
- `logging_config.py` — Logging setup and formatters
- `cities.json` — Reference data for supported cities
- `crime_categories.json` — Crime category taxonomy
- `__init__.py` — Package initialization
