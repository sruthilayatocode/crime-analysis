# IoT

## Purpose
IoT device simulation for GPS tracking and real-time proximity alert generation when users approach crime hotspots.

## Files
- `gps_tracker.py` — GPS location tracking and simulation
- `proximity_alert.py` — Alert generation and delivery
- `__init__.py` — Package initialization
